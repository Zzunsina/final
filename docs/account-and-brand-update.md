# 아이디·관리자 로그인·로고 변경

아래는 첫 변경 당시 기록입니다. 이후 사용자 요청으로 이메일 로그인을 중단하고 가입 규칙을 변경했습니다.
현재 동작은 [최신 가입·로그인 규칙](signup-rules.md)을 따릅니다.

사용자 요청에 따라 기존 개요서의 이메일 전용 로그인 기준을 변경했습니다.

## 계정

- 회원가입에 필수 `loginId`를 추가합니다. 이메일은 연락용 필드로 유지합니다.
- 아이디는 영문·숫자로 시작하는 4~30자의 영문, 숫자, `_`, `-`입니다.
- 서버가 앞뒤 공백 제거·소문자 정규화 후 저장하며 UNIQUE 인덱스로 중복 가입을 방지합니다.
- Flyway V5가 users.login_id를 추가합니다. 기존 회원의 이메일·비밀번호와 데이터는 유지합니다.
- 기존 회원은 login_id가 없어도 이메일로 계속 로그인할 수 있습니다.
- 일반 로그인 API는 loginId 또는 기존 email 필드를 지원합니다.

## 관리자

- 화면 `/admin/login`, API `POST /api/auth/admin/login`을 추가했습니다.
- 일반 로그인 화면과 푸터에 진입 링크를 추가했습니다.
- 서버에서 비밀번호·회원 활성 상태·ADMIN 역할을 확인한 후 쿠키를 발급합니다.
- 관리자 가입이나 기존 회원에게 관리자 권한을 주는 기능은 추가하지 않았습니다.
- 기존 관리자 계정은 아이디가 없으면 이메일로 로그인합니다.
- CSRF와 로그인 요청 제한을 관리자 로그인에도 적용합니다.

## 로고

- 사용자 제공 JPG를 `public/images/jobbridge-logo.jpg`에 원본 그대로 복사했습니다.
- 헤더·푸터·로그인 화면에 적용하고 CSS로 여백과 크기를 조절했습니다.

## 검증 및 실행

- 백엔드 테스트 8개 통과: 기존 6개와 아이디·관리자 로그인 검증 2개.
- 프런트 lint·build 통과.
- 브라우저에서 구직자·기업 회원가입의 아이디 입력과 관리자 로그인 화면, 로고를 확인했습니다.
- IntelliJ에서 백엔드를 중지 후 다시 실행하면 V5가 자동 적용됩니다.
- 프런트는 npm run dev를 유지한 채 새로고침합니다. 재시작 전 이전 백엔드로는 새 아이디 로그인을 사용할 수 없습니다.
