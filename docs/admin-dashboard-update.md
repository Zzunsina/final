# 회원가입 완료 안내와 관리자 대시보드

## 가입 완료 안내

회원가입 API가 성공한 뒤 로그인 화면으로 이동하면서
**회원가입이 완료되었습니다.** 안내를 표시합니다.
기업 가입자는 기업 로그인 탭, 개인 가입자는 개인 로그인 탭이 선택됩니다.
실패한 가입 요청에는 완료 안내를 표시하지 않습니다. 안내는 닫을 수 있습니다.

## 관리자 대시보드

`GET /api/admin/dashboard`에서 실제 DB 데이터를 집계합니다.
가짜 수치·증감률을 넣지 않으며 데이터가 없으면 0과 빈 상태를 표시합니다.

- 전체 회원(개인·기업), 승인 활성 기업의 게시 공고, 누적 지원, 취업 완료 연계.
- 오늘 가입·지원 수, 기업 승인·공고 심사·미답변 문의·신규 연계 대기 수.
- 최근 7일 신규 회원/입사 지원 전환 그래프와 지원 상태별 분포.
- 승인·심사 대기 최근 5건, 미답변 문의 4건, 최근 가입 회원 5명, 진행 연계 4건.
- 관리 화면 바로가기, 선택한 항목 위치로 스크롤·강조, 새로고침과 조회 시각.
- 데스크톱 다중 열 레이아웃과 모바일 카드·표 스크롤.

회원 합계와 가입 추이는 ADMIN을 제외합니다. 취업 완료 수는 사람이 아닌 EMPLOYED 연계 건수입니다.
공고 집계는 승인된 활성 기업의 PUBLISHED이며 마감일이 지나지 않은 공고입니다.
오늘·최근 7일의 날짜 경계는 Asia/Seoul, 시각 조회 조건은 UTC Timestamp를 사용합니다.
관리자 역할은 서버에서 확인하며 대시보드 응답에 연락처·생년월일·성별·내부 메모·문의 본문을 포함하지 않습니다.

## 검증

- 백엔드 테스트 12개 통과. 대기 목록·실제 집계·7일 범위·민감 필드 제외·관리자 권한 확인 포함.
- 프런트 lint·production build 통과.
- 서버 렌더링으로 가입 완료 안내의 표시/미표시와 기업/개인 탭 선택 확인.
- 독립된 H2 메모리 DB와 8081/5175 포트에서 관리자 로그인·대시보드·그래프 전환·회원 관리 이동 확인.
- 390px 화면에서 페이지 전체의 가로 넘침 없음. 표는 내부 가로 스크롤을 사용합니다.
- 실제 MariaDB와 IntelliJ의 실행 프로세스는 변경하지 않았습니다.

## 적용

IntelliJ 서버를 중지 후 다시 실행하고 프런트 화면을 새로고침합니다.
이번 변경은 추가 DB migration이 필요하지 않습니다.
기본 연결은 8080이며 별도 검증 환경에만 Vite의 BACKEND_URL 환경 변수를 사용했습니다.
