# 검증 기록

검증일: 2026-10-20, Windows, JDK 17.0.19, Node.js 24.19.0.

## 자동 검증

| 항목 | 결과 |
|---|---|
| Gradle `test --no-daemon` | 통과: 6개 테스트, 실패 0 |
| ESLint `src` | 통과: 오류·경고 0 |
| Vite production build | 통과: 모듈 103개, JS 약 312.53 kB / gzip 100.33 kB |
| Java Prettier | 전체 Java 포맷, 4칸 들여쓰기 |
| JSX/CSS Prettier | 전체 프런트 소스 포맷, 2칸 들여쓰기 |

테스트 DB는 H2 메모리 DB입니다. Flyway V1~V3가 빈 테스트 DB에 적용됩니다.

통합 테스트가 확인한 내용:

- CSRF 없는 로그인 403, 비로그인 이력서 접근 401.
- 구직자의 관리자 접근 403, 타인 이력서 접근 404.
- 공개 가입 body의 role=ADMIN이 실제 가입 권한에 영향을 주지 않음.
- 공개 공고 응답에 심사 메모가 포함되지 않음.
- 타인 이력서 지원 차단, 제출 당시 이력서 스냅샷 보존.
- 동일 공고 중복 지원 차단, 지원에 사용한 이력서 삭제 제한, 마감 공고 지원 거절.
- 단계별 기업 상태 변경, 면접 키·본문 중복 및 충돌 처리.
- 구직자 응답에 기업 내부 면접 메모 미노출.
- 지원 취소 시 예정 면접 취소, 취소한 지원의 재활성화 차단.
- 미승인 기업의 지원자 접근 차단, 해당 기업 공고 공개 차단.
- 로그아웃 이후 이전 access 쿠키로 보호 API 접근 차단.
- 4개 동시 지원 요청 중 1개만 성공.
- 동시 기본 이력서 지정 후 기본 이력서 1개 유지.
- 4개 동시 취업연계 신청 중 1개만 성공.

## 브라우저 확인

- 실제 Spring Boot dev 서버와 Vite proxy를 연결해 홈에서 샘플 공고 6개와 공지를 확인했습니다.
- 개발용 구직자 로그인 후 이름과 구직자 메뉴가 표시되는 것을 확인했습니다.
- 본인 기본 이력서와 수정·삭제 행동을 조회했습니다.
- 390×844 홈 화면: 페이지 가로 넘침 없음.
- 360×800, 768×1024 이력서 화면: 페이지 가로 넘침 없음, 카드·버튼·모바일 메뉴 정상 표시.
- 회원 메뉴는 좁은 화면에서 가로 스크롤합니다. 전체 페이지 가로 넘침과 구분됩니다.

## 아직 검증하지 않은 범위

- MySQL 실서버 적용과 MySQL의 동시성·정렬·시간 동작.
- 모든 역할의 모든 화면을 통과하는 브라우저 시나리오.
- 1440px 전용 검사, 키보드 전체 흐름, 화면 확대·스크린리더.
- SMTP 재설정, 운영 HTTPS·reverse proxy, 운영 배포.
- 관리자의 모든 심사·연계 상태 조합과 refresh 경합·종료 시점 경합.

위 미검증 항목을 완료로 표시하지 않습니다.
